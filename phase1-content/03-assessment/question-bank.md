## Definitions

### P1-QB-013 - Traditional software, defined
*MC · Traditional software · foundational · LO1 · Use: check, diagnostic, retake · Remediation: traditional-software block*
**Which description matches traditional software?**
A) Software that follows rules people wrote, so the same input gives the same output *(correct)* · B) Software that improves itself as you use it · C) Software that runs only on older computers · D) Software with no user interface
**Correct:** Correct - written rules and repeatable output are the definition.
**Incorrect:** Not quite - age and interfaces are irrelevant, and self-improvement isn't part of it. The definition is authored rules producing the same output for the same input. Review: Traditional software.

### P1-QB-014 - AI, defined
*MC · AI characteristics · foundational · LO3 · Use: check, diagnostic, retake · Remediation: AI block*

A) Software that talks with people · B) Systems that find patterns in data to classify, predict, or generate things *(correct)* · C) Any system that works automatically · D) The newest version of any software
**Correct:** Correct - pattern-based classify/predict/generate is the working definition.
**Incorrect:** Not quite - conversation, autonomy, and newness are all beside the point. The defining move is applying patterns learned from data. Review: Artificial intelligence.
