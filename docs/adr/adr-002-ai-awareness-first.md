# ADR-002 — AI Awareness is the first pathway

**Status:** Accepted · **Date:** 2026-07-31 · **Category:** Product

## Context
The broadest addressable audience is beginners who use AI tools without understanding them; every later pathway assumes the mental models this level builds.

## Decision
Level 1 (AI Awareness) ships first, with the AI-vs-automation-vs-software distinction as its opening section — the single highest-leverage confusion to resolve.

## Alternatives considered
Start with Practical AI (rejected: skips the models that make practice safe and transferable); start with role-based technical content (rejected: smallest audience, deepest prerequisite chain).

## Consequences
- **Positive:** Maximum audience; foundation for all pathways; strongest authority-building surface.
- **Negative:** Advanced learners see little for themselves in Phase 1 (mitigated by ADR-005).
