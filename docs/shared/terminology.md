# Terminology

Fixed vocabulary. Introducing a synonym is a defect, not a style choice.

## Learner-facing names (exact)
- Content layers: **Quick Explanation**, **Explore Further**, **Go Deeper**, **Apply It**
- Steps: **Lesson → Activity → Knowledge check → Assessment**
- Graded vs practice: **assessment** (graded) / **knowledge check** (practice). Banned: *test, exam, quiz*.
- Section states: **Not started / In progress / Complete**
- Activity: **Sort the System**; categories: **Traditional software · Automation · AI-assisted · Combination · Not enough information**
- Future sections: **"Coming soon"** - never lock icons
- Failure copy never uses the word *fail*; frame is "Here's what to review"

## Internal terms
- **Canonical record** - single source of truth per concept ([../content/knowledge-model.md](../content/knowledge-model.md))
- **Blueprint category** - assessment competency dimension ([../content/assessments.md](../content/assessments.md))
- **Actor** - resolved identity in server actions: registered `{userId}` or guest `{anonymousId}`
- **ProgressSnapshot** - shared progress type, storage-agnostic (device or account)
- **Vertical slice** - the one complete Phase 1 section
- **LO1–LO10** - learning objectives; **M1–M6** - misconception IDs; **S01–S13** - screens; **J1–J4** - journeys; **M0–M9** - build milestones; **D1–D8** - roadmap dependencies; **F1–F3** - analytics funnels

## Banned in learner copy
*test/exam/quiz · fail · simply/just/easy · cutting-edge/revolutionary ·* anthropomorphic AI verbs (*think, know, understand, believe, want* - use *detect, classify, generate, flag*).
