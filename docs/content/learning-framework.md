# Learning Framework

Canonical learning model; every pathway inherits it.

## Competency model
Seven levels (Phase 0): AI Awareness → AI Literacy → Responsible AI Use → Practical AI Application → AI Product & Engineering Awareness → Role-Based → Company-Specific. Phase 1 teaches within Level 1. **Competency = demonstrated ability**: passing the assessment, regardless of content consumed. Levels enter independently; prerequisites only where success is impossible without them (none within Level 1).

## Layered learning
| Layer | Job | Budget/concept | Obligation |
|---|---|---|---|
| Quick Explanation | essential idea + one familiar example; sufficient to attempt the assessment | 80–120 words | always visible; must stand alone |
| Explore Further | second examples, comparisons, edge cases | 150–250 | voluntary; labelled with reading time |
| Go Deeper | technical framing (rules vs learned patterns, training, thresholds) | 180–300 | voluntary; never required to pass unless testing proves otherwise |
| Apply It | retrieval: activity, check, assessment | - | required via any route |

**Standalone test (hard rule):** a learner reading only Quick layers must be able to answer every foundational assessment question. QA verifies by mapping foundational questions to Quick-layer sentences. This is what keeps depth voluntary instead of hidden required reading.

## Routes & progression
Standard (lesson→activity→check→assessment) · assessment-first (identical rules, no penalty framing) · remediation (fail → category-targeted review → different-combination retake). Passing is the only completion condition; consumption/time/depth are analytics signals. Remediation reteaches **differently** - never the sentences that already failed ([misconceptions.md](misconceptions.md)).
