# Misconceptions (M1-M7) & Remediation

Canonical register: callouts, feedback, and questions reference IDs, never restate. Each entry names why the belief is *reasonable* - respect is what makes correction land.

| ID | Misconception | Why it's held | Corrective strategy |
|---|---|---|---|
| M1 | complex/impressive = AI | marketing labels everything AI | contrast case: complex tax calculator is still rules; bigger vending machine is still a machine (LO8) |
| M2 | automation = AI | both remove effort; outcomes look identical | automation = how work flows; AI = how decisions are made; dominoes vs forecast side by side |
| M3 | AI thinks like a person | conversational interfaces invite it | pattern-without-comprehension; the forecast doesn't know about your picnic; anthropomorphic verbs banned in our own copy |
| M4 | same input → same AI answer | lifetime of deterministic software | probabilistic passage + spam false-positive; variability is designed, not broken (LO6) |
| M5 | you can tell from the interface | interfaces are all learners see | chatbot minimal pair (scenarios 6/7) + restaurant kitchen; "Not enough information" is a skilled answer (LO9) |
| M6 | AI works alone | media framing as autonomous agent | the diagram is the counter-argument: AI as one layer among five, human review explicit |
| M7 | AI is objective because it is a machine | machines feel impartial next to people, and the output arrives without visible opinion | bias is inherited from data, not chosen: the system reproduces what its examples contained, so "no human decided this" is not the same as "no human influence" (AIA-5) |

## Remediation principles
1. **Reteach differently** - lead with the example/analogy the first pass held back; never repeat failed sentences.
2. **Name the confusion, not the error** - "these two are easy to mix up because…" precedes correction.
3. **One concept at a time** - multi-category failures present sequentially, worst first.
4. **Close the loop** - each remediation block ends with an optional mini-confirm targeting the exact confusion; correct answers named as progress.

Reinforcement inside Phase 1 = retrieval spacing (concept → activity → check → assessment → takeaway); cross-lesson spaced review is Phase 2 (category tags already support it).
